# Hand Gesture Recognition using SVM

## Objective
This project recognizes different hand gestures using Machine Learning and image processing techniques.

## Technologies Used
- Python
- OpenCV
- NumPy
- Matplotlib
- Scikit-learn

## Machine Learning Algorithm
Support Vector Machine (SVM)

## Dataset
Leap Gesture Recognition Dataset from Kaggle

## Steps Performed
1. Image Loading
2. Grayscale Conversion
3. Image Resizing
4. Data Preprocessing
5. Train-Test Split
6. SVM Model Training
7. Gesture Prediction

## Output
The model identifies different hand gestures from image data.
