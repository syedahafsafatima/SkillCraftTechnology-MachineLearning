# Cats vs Dogs Classification using SVM

## Objective
This project classifies images of cats and dogs using a Support Vector Machine (SVM) model.

## Technologies Used
- Python
- OpenCV
- NumPy
- Matplotlib
- Scikit-learn

## Machine Learning Algorithm
Support Vector Machine (SVM)

## Dataset
Dog and Cat Classification Dataset from Kaggle

## Steps Performed
1. Image Loading
2. Grayscale Conversion
3. Image Resizing
4. Data Preprocessing
5. Train-Test Split
6. SVM Model Training
7. Image Classification

## Output
The model predicts whether the image contains a cat or a dog.
